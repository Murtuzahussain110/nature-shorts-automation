# Nature Shorts Automation

This GitHub Actions project creates one 30-second vertical nature/travel motivational Short and uploads it to YouTube.

## What it does
- Searches Pexels for a nature/travel video (requires a Pexels API key).
- Crops the footage to 9:16 (1080x1920).
- Generates original English motivational narration using the female `en-US-AriaNeural` voice.
- Generates a quiet original synthesized ambient music bed (no third-party song recording).
- Burns captions into the video.
- Uploads the Short through YouTube Data API v3.

## Required GitHub Actions secrets
- `PEXELS_API_KEY`: API key from your Pexels account.
- `YOUTUBE_CLIENT_JSON`: complete contents of the downloaded Google OAuth Desktop client JSON file.
- `YOUTUBE_REFRESH_TOKEN`: OAuth refresh token for the YouTube channel owner account.

Optional repository variable:
- `YOUTUBE_PRIVACY_STATUS`: `private` (default), `unlisted`, or `public`. Start with `private` until you have checked the first upload.

## Important OAuth notes
`YOUTUBE_CLIENT_JSON` alone is not enough. You must obtain a refresh token using the same Desktop OAuth client and the Google account that owns the channel. Keep both the JSON and refresh token private. Never commit them to the repository.

For OAuth testing, the Google account must be listed as a test user. YouTube API projects that have not passed the required audit may be restricted to private uploads. The first upload is intentionally private by default.

## Schedule
The cron is `0 13 * * *`, which is 13:00 UTC (18:00 Pakistan time). GitHub may delay scheduled runs. The workflow can also be run manually.

## Copyright and platform safety
Pexels footage is sourced through its API; check the source record saved in `output/source_info.txt` and comply with Pexels' current license/terms. Narration and music are generated by this project. Do not upload material you do not have rights to use. This project does not guarantee views or monetization.
