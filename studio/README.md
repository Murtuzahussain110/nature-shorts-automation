# Mobile Cartoon Studio (prototype)

A mobile-first, installable PWA shell for drafting Urdu cartoon Shorts: story beats, dialogue, subtitle preview and a copyable video-generation prompt.

## Important status
This is **not yet an AI video renderer**. It does not generate character images, AI voices, lip-sync or MP4 files. Those require a connected generation provider or a verified free model/runtime. No paid API or Higgsfield credits are used by this prototype.

## Open
After GitHub Pages deployment, open the Pages URL ending in /studio/. On Android Chrome, use **Add to Home screen** to install the PWA.

## Next integration gate
Connect a real video provider only after verifying its free quota and exact output capabilities. Keep uploads private until manually reviewed.
